# 🎨 Color Palette Generator

A simple and attractive Color Palette Generator built using HTML, CSS and JavaScript.

## 🚀 Features

- 🎲 Generate random color palettes
- 🎨 Generates 5 colors at once
- 📋 Copy individual color codes
- 📱 Responsive design
- ⚡ Fast and lightweight

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ▶️ How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Click **Generate Palette**.
4. Click **Copy** to copy any HEX color code.
